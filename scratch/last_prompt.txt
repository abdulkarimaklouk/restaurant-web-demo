## 1. Initial Inspection

- Existing design tokens and Settings visual style.

## 2. Chart Layout

Create a full-width Sales Overview card containing:

- Section title: Sales Overview / نظرة عامة على المبيعات.
- Sales / Orders segmented toggle.
- Chart plotting area.
- Vertical Y-axis labels.
- Horizontal X-axis time labels.
- Blue smooth line.
- Subtle gradient area fill beneath the line.
- Circular data points.
- Vertical dashed guide for the active point.
- Floating tooltip displaying the selected value and time.

**Sales**
- Display revenue values.
- Format Y-axis values using the existing currency formatter.

**Orders**
- Display the number of confirmed orders.
- Use integer Y-axis values.
- Tooltip shows the order count and corresponding time period.

Switching modes must update the chart without resetting the selected date filter.
